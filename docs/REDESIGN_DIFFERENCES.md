# REDESIGN_DIFFERENCES — original site vs v1 vs v2

## Diagnosis of v1 (why it was too similar)
- Same section order as the original (hero video → presentation → treatments → before/after → studio → contacts).
- Same hero: the original site's studio video as a full-width background, with the slogan.
- Treatments as photo cards (the original uses a photo slider): same logic, new layout.
- Studio as a photo grid; header with a plum slogan bar + black bar (identical structure).

## Comparison
| Area | Original site | v1 | v2 — The Smile Experience |
|---|---|---|---|
| Layout | Stacked Elementor sections | Same order, editorial | 8 chapters "Experience 01–08", narrative story, chapter progress indicator |

## 3D elements introduced
1. SmileRibbon — sculpture of two pearl bands along the smile curve (hero + closing).
2. DentalArch — procedural stylised arch (14 shaped teeth, glass base) with 3 interactive modes.
3. TreatmentScene — 4 illustrative scenes sharing the same geometry.
4. StudioJourney — photo planes in 3D space with camera travel.

## Identity elements preserved
Official logo (unaltered), the 8 palette colours, the slogan "Il tuo sorriso pazzesco", verified clinical/professional data, authentic photos of the doctor and the studio.
